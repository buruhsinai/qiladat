Folder ini untuk gambar milik halaman /dien/kajian/ saja (mengikuti pola
situs: aset dikoleksikan per-folder halaman, bukan folder aset global).

Taruh gambar jadwal kajian (atau gambar lain khusus halaman ini) di sini,
lalu tautkan dari dien/kajian/index.html dengan path relatif, contoh:

  <img src="img/jadwal-kajian.jpg" alt="Jadwal kajian luring & live streaming" loading="lazy">

Tempat penyisipannya sudah ditandai dengan komentar HTML di index.html,
di dalam panel "Kajian Luring & Live Streaming".

Hapus file README.txt ini kapan saja setelah folder terisi gambar asli —
ia hanya penanda supaya folder kosong ini ikut tersimpan di dalam zip.
