Converter

"Belajar mengubah representasi tanpa mengubah makna." Bukan soal menganalisis data — soal menerjemahkan struktur A menjadi struktur B, dan membuktikan tidak ada makna yang diam-diam hilang di tengah jalan.

Istilah yang dipakai di sini

parsing
membaca teks mentah dan memahaminya sebagai struktur (mis. teks CSV → baris & kolom)
serialization
mengubah struktur data dalam memori menjadi teks (mis. objek JS → teks CSV)
deserialization
kebalikannya — teks kembali menjadi struktur data
mapping / schema
aturan bagaimana satu bentuk struktur dipetakan ke bentuk lain (mis. objek bersarang → nama kolom dengan titik)
escaping
menandai karakter yang punya arti khusus di format tujuan supaya dibaca sebagai teks biasa, bukan sintaks
encoding
aturan mengubah data jadi urutan byte tertentu (mis. teks → UTF-8 → Base64)
data integrity
jaminan bahwa data yang sudah diubah bentuk, saat dikembalikan lagi, masih sama persis maknanya
Prinsip proyek ini: transformasi tidak boleh diam-diam menghilangkan makna. Karena itu, tiap konverter di bawah selalu mengubah balik hasilnya (round-trip) dan membandingkannya dengan data asli — bukan cuma menunjukkan hasil yang "terlihat benar".

Markdown → HTML

      
Transformasi satu arah yang disengaja — HTML bisa menyatakan hal yang Markdown tidak bisa, jadi mengembalikannya ke Markdown lagi pasti kehilangan sesuatu. Yang dijaga di sini: karakter < > & di dalam teks tidak boleh diam-diam berubah jadi tag HTML sungguhan.

      
      
      

      

        

          
          

        

        

          
          

        

      

      

    

  


  
  

    

      
Base64 ↔ Teks

      
Base64 mengubah byte, bukan karakter. Cara yang naif (btoa langsung) diam-diam berasumsi setiap karakter = 1 byte — asumsi yang pecah begitu teksnya bahasa Arab atau huruf beraksen. Ini sangat relevan untuk teks kitab dan data ilmiah berbahasa Arab nantinya.

Base64 ↔ File

      
Encode file jadi teks Base64, lalu decode lagi jadi file — dibuktikan identik bit demi bit lewat hash SHA-256, bukan sekadar "kelihatannya sama".

      

        
        
Pilih file apa saja (gambar, PDF, dsb.) — tidak diunggah ke mana-mana, semua diproses di peramban.
