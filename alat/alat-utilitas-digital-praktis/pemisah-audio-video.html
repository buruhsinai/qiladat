Pemisah Audio dari Video

Ambil jalur suara dari file video langsung di browser Anda — tanpa upload, tanpa library eksternal, murni API bawaan browser.

⚠ Baca dulu sebelum memakai

Proses ini berjalan real-time — selama durasi video itu sendiri. Video diputar diam-diam di latar, audionya direkam ulang saat itu juga. Video 10 menit akan butuh ±10 menit untuk diekstrak, bukan proses instan.

  • Hasil bukan salinan bit-perfect dari audio asli — audio direkam ulang (biasanya format WebM/Opus), jadi ada sedikit kompresi ulang, meski umumnya kualitasnya masih sangat baik untuk kebutuhan umum.
  • Jangan tutup tab atau pindah ke tab lain selagi proses berjalan — beberapa browser membatasi/menghentikan tab yang tidak aktif, yang bisa menghentikan proses di tengah jalan.
  • File video Anda tidak pernah diunggah ke server mana pun — semua terjadi di perangkat Anda, dan halaman ini bahkan tidak memuat apa pun dari internet setelah pertama dibuka.

Cara Kerja

Apa yang Sebenarnya Terjadi

Video Anda diputar (dibisukan dari speaker secara langsung), lalu sinyal audio yang sedang didekode browser "disadap" lewat Web Audio API (createMediaElementSource), dialirkan ke MediaRecorder yang merekamnya jadi file audio baru — mirip cara kerja perekam layar merekam suara sistem, hanya di sini sumbernya adalah elemen video itu sendiri, bukan seluruh output speaker.

Batasan

Kapan Alat Ini Tidak Cocok

  • Bukan salinan lossless. Untuk ekstraksi audio bit-perfect (tanpa rekompresi sama sekali), Anda tetap butuh alat seperti FFmpeg asli di desktop — alat ini adalah "rekam ulang real-time", bukan "salin aliran audio mentah".
  • Waktu proses = durasi video. Tidak ada cara mempercepatnya di alat berbasis browser murni seperti ini — video benar-benar harus diputar dari awal sampai akhir.
  • Format keluaran terbatas pada yang didukung MediaRecorder browser Anda — umumnya WebM/Opus di Chrome & Firefox; Safari punya dukungan yang berbeda/lebih terbatas.
  • Tab harus tetap aktif & terlihat selama proses — beberapa browser menghentikan/menunda tab di latar belakang untuk hemat baterai.
Referensi
  • Web Audio API (AudioContext, MediaElementAudioSourceNode, MediaStreamAudioDestinationNode) — standar W3C untuk pemrosesan audio di browser.
  • MediaRecorder API — standar W3C untuk merekam aliran media (audio/video) langsung di browser.

Untuk ekstraksi lossless/format lain, pertimbangkan FFmpeg desktop. Ada pertanyaan atau kendala? Hubungi kami.
