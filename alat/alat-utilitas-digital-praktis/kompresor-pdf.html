Kompresor PDF

Perkecil ukuran file PDF langsung di browser Anda — tidak ada file yang diunggah ke server mana pun. Cocok terutama untuk PDF hasil scan/foto.

⚠ Baca dulu sebelum memakai

Alat ini butuh koneksi internet — berbeda dari kalkulator JAZMI lainnya, alat ini memuat dua library (pdf.js & pdf-lib) dari CDN saat halaman dibuka. File PDF Anda sendiri tetap 100% diproses lokal di perangkat Anda, tidak pernah terkirim ke server mana pun.

  • Mode Gambar mengubah setiap halaman jadi gambar terkompresi. Ukuran berkurang drastis untuk PDF hasil scan, tapi teksnya jadi tidak bisa lagi di-select/dicari/disalin. Jangan pakai mode ini untuk dokumen yang teksnya masih Anda perlukan.
  • PDF yang formatnya rumit (form isian, tanda tangan digital, lapisan keamanan) mungkin tidak diproses sempurna.
  • File besar / halaman banyak bisa memakan waktu — proses berjalan di perangkat Anda sendiri, jadi kecepatan tergantung spesifikasi HP/laptop Anda.

Cara Kerja

Apa yang Sebenarnya Terjadi

Mode Gambar (default): tiap halaman PDF dirender ulang jadi gambar (lewat pdf.js), lalu gambar itu dikompres sebagai JPEG pada kualitas & resolusi sesuai preset, lalu disusun jadi PDF baru berisi gambar-gambar tersebut (lewat pdf-lib). Ini teknik "rasterize & rekompresi" yang sama dipakai banyak alat kompresi PDF berbasis scan.

Mode Ringan: PDF dibuka lalu ditulis ulang strukturnya (object stream dioptimalkan, metadata dirapikan) tanpa mengubah kontennya sama sekali — teks & gambar asli tetap vektor/utuh. Pengurangan ukurannya biasanya jauh lebih kecil daripada Mode Gambar, tapi teks tetap bisa disalin/dicari.

Batasan

Kapan Alat Ini Tidak Cocok

  • Mode Gambar menghilangkan teks yang bisa diseleksi. Jika PDF Anda adalah dokumen teks (bukan scan) dan Anda butuh teksnya tetap bisa dicari/disalin, pakai Mode Ringan — atau terima bahwa Mode Gambar bukan pilihan tepat untuk kasus itu.
  • Mode Ringan seringkali hanya mengurangi ukuran sedikit (kadang nyaris tidak berubah) untuk PDF yang sudah dioptimalkan sebelumnya — ini realitas format PDF, bukan bug alat.
  • PDF dengan proteksi kata sandi, tanda tangan digital, atau form interaktif kompleks berisiko rusak/berubah setelah diproses — cadangkan file asli Anda sebelum mengganti.
  • Karena semua proses berjalan di perangkat Anda (bukan server), file besar (puluhan-ratusan MB) atau puluhan halaman bisa terasa berat/lambat, tergantung spesifikasi perangkat.
  • Butuh koneksi internet saat pertama membuka halaman ini (memuat pdf.js & pdf-lib) — setelah termuat, pemrosesan filenya sendiri tidak butuh internet lagi.
Referensi
  • pdf.js — proyek Mozilla untuk membaca & merender PDF di browser (lisensi Apache).
  • pdf-lib — pustaka untuk membuat & memodifikasi PDF di JavaScript (lisensi MIT).
  • Prinsip downsampling & rekompresi JPEG sebagai teknik kompresi gambar dalam dokumen — praktik umum di banyak alat kompresi PDF berbasis scan.
