Kompresor Gambar

Perkecil ukuran banyak gambar sekaligus langsung di browser Anda — tidak ada file yang diunggah ke server mana pun. Pengaturan default meniru persis skrip generate-manifest.py yang dipakai di arsip/gambar/.

✓ Cocok untuk alur kerja Arsip Gambar

Alat ini untuk langkah sebelum Anda menaruh gambar ke folder arsip/gambar/ di situs. Kompres di sini dulu (opsional — generate-manifest.py sebenarnya juga mengompres otomatis saat dijalankan), lalu taruh hasilnya ke folder sumber yang sesuai. Nama file TIDAK diubah (kecuali PNG yang dikonversi ke JPEG, ekstensinya ikut berubah jadi .jpg) — penting supaya nama timestamp asli (mis. hasil ekspor Facebook) tetap terbaca sebagai tanggal oleh skrip manifest.

⚠ Baca dulu sebelum memakai

Kompresi gambar sendiri TIDAK butuh internet — memakai fitur bawaan browser (Canvas), semua diproses lokal di perangkat Anda. Internet cuma dipakai sekali saat memuat halaman ini dan (opsional) saat memuat pustaka JSZip untuk tombol "Unduh Semua (ZIP)".

  • Kalau JSZip gagal dimuat (mis. tanpa internet), tombol ZIP tersembunyi — Anda tetap bisa unduh tiap gambar satu per satu.
  • PNG dengan transparansi asli (alpha) tetap disimpan sebagai PNG (tidak dikonversi ke JPEG) — sama seperti logika generate-manifest.py.
  • Gambar yang sudah kecil (di bawah ambang) tetap ikut diproses ulang oleh alat ini (beda dengan skrip Python yang otomatis melewati file yang sudah kecil) — hasilnya tetap aman dipakai, hanya saja pengurangan ukurannya mungkin nyaris tidak terasa untuk file yang memang sudah kecil.

Cara Kerja

Apa yang Sebenarnya Terjadi

Tiap gambar digambar ulang ke <canvas> pada ukuran sisi-terpanjang sesuai preset (default 1600px, tidak diperbesar kalau aslinya lebih kecil), lalu disimpan sebagai JPEG pada kualitas sesuai preset (default 82%). Kalau file asli PNG dan terdeteksi punya kanal transparansi (alpha) yang benar-benar terpakai, hasilnya tetap disimpan sebagai PNG (bukan dikonversi) — sama seperti aturan yang dipakai generate-manifest.py untuk PNG besar tanpa transparansi.

Batasan

Kapan Alat Ini Tidak Cocok

  • Ini bukan pengganti generate-manifest.py — alat ini hanya mengompres file, tidak menulis/mengubah data/gambar.json. Setelah gambar (dari sini atau langsung dari HP) ditaruh ke folder arsip/gambar/, skrip manifest tetap perlu dijalankan supaya galeri & panel Home ikut memperbarui.
  • Deteksi transparansi dilakukan dengan sampling piksel (bukan memindai tiap piksel) demi kecepatan — untuk PNG dengan area transparan sangat kecil/tipis, ada kemungkinan kecil terlewat dan dikonversi ke JPEG. Kalau ragu, cek hasilnya sebelum menghapus file asli.
  • Banyak file besar sekaligus bisa terasa berat/lambat di HP dengan RAM kecil, karena semua diproses di memori perangkat Anda.
  • Format selain PNG/JPEG/WEBP (mis. HEIC langsung dari kamera iPhone) mungkin tidak terbaca browser — ekspor/convert ke JPEG dulu di HP sebelum diunggah ke sini kalau begitu.
Referensi
  • Canvas API & canvas.toBlob() — fitur bawaan browser untuk menggambar ulang & mengekspor gambar (tanpa pustaka eksternal).
  • JSZip — dipakai hanya untuk membungkus banyak hasil jadi satu file ZIP (lisensi MIT), dimuat dari CDN saat tombol "Unduh Semua" dipakai.
  • Pengaturan default (1600px, kualitas 82%, ambang PNG 500KB) disamakan persis dengan generate-manifest.py di arsip/gambar/.
