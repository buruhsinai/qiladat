Regu Damkar: Air atau Gas?

Kota malam, api menjalar dari bangunan ke bangunan. Kamu memimpin regu pemadam: pilih alat yang tepat untuk tiap jenis api, atau akibatnya nyata.

Pos Damkar

Langkah 1: ketuk bangunan yang menyala di peta. Langkah 2: ketuk alatnya.

Cara bermain

  • Ketuk bangunan yang terbakar untuk memeriksanya, lalu ketuk Air atau Gas CO₂. Mobil pemadam berangkat lewat jalan raya tercepat, berhenti di tepi jalan terdekat, lalu selangnya menjangkau bangunan.
  • Salah alat? Ketuk api yang sedang ditangani, lalu ketuk alat lain untuk mengganti di tengah tugas.
  • Api menjalar sendiri ke bangunan di dekatnya. Bangunan basah lebih sulit terbakar; lahan kosong dan jalan memperlambat api.

Algoritma di balik layar

Api menjalar memakai automata seluler: tiap petak hanya melihat tetangganya. Pola kebakaran besar muncul dari aturan kecil itu. Bara terbang memakai Lévy flight (lompatan berekor gemuk, seperti pada Cuckoo Search dan Penyerbukan Bunga): kebanyakan jatuh dekat, sesekali sangat jauh.

Rute mobil memakai BFS biasa, bukan algoritma alam. Graf jalannya kecil, jadi cara eksak lebih cepat dan lebih tepat. Algoritma alam bukan satu-satunya pilihan.

Lihat rumpun algoritma serupa di Laboratorium Algoritma Alam, termasuk Automata Seluler, Cuckoo Search, dan Ngengat-Api.

Batasan. Kelas api dan akibat salah alat disederhanakan untuk belajar. Parameter penjalaran api disetel untuk keseruan bermain dan belum dikalibrasi terhadap fisika kebakaran sungguhan. Di dunia nyata, regu juga memutus listrik lebih dulu dan mengutamakan keselamatan warga.
