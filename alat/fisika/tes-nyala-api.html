Tes Nyala Api

Kenapa garam dapur di atas api berubah oranye, dan kembang api bisa merah/hijau/ungu? Prinsipnya sama persis dengan Model Atom Bohr (No. 9) — elektron logam meloncat turun antar level energi, memancarkan cahaya di panjang gelombang tertentu. Bedanya, ini kejadian yang jauh lebih sering kita lihat langsung: dapur, kembang api, api unggun.

Kenapa warnanya beda-beda?

Tiap unsur punya susunan elektron dan jarak antar level energi yang unik — seperti sidik jari. Saat dipanaskan, elektron loncat ke level lebih tinggi lalu jatuh kembali sambil melepas energi sebagai foton cahaya. Selisih energi antar level itulah yang menentukan warnanya.

E_foton = h × f = E_level_tinggi − E_level_rendah

Ini rumus dasar yang sama dengan deret spektrum hidrogen di Model Atom Bohr — hanya saja di sini unsurnya jauh lebih kompleks (bukan hidrogen satu elektron), sehingga warnanya adalah campuran banyak garis spektrum, bukan satu warna murni tunggal.

Batasan

Warna nyala sungguhan sedikit bervariasi tergantung suhu api dan kemurnian bahan — warna yang ditampilkan di sini adalah warna khas yang paling umum dikutip, bukan pengukuran spektrometer presisi.
