Pisah & Gabung PDF

Ekstrak halaman tertentu, pecah jadi banyak file, atau satukan beberapa PDF jadi satu — semua diproses lokal di browser Anda, tanpa upload.

⚠ Baca dulu sebelum memakai

Alat ini memuat pustaka pdf-lib & JSZip dari CDN saat dibuka — butuh internet sekali di awal. File PDF Anda sendiri tetap 100% diproses di perangkat Anda, tidak pernah diunggah ke server mana pun.

  • Halaman disalin apa adanya (vektor/teks/gambar tetap utuh, tidak dirender ulang) — kualitas hasil identik dengan file asli, tidak ada kompresi/kehilangan kualitas.
  • PDF terenkripsi/berkata-sandi mungkin gagal diproses — buka proteksinya dulu sebelum diunggah ke alat ini.

    Kapan Alat Ini Tidak Cocok

    • PDF dengan kata sandi/enkripsi harus dibuka proteksinya lebih dulu di alat lain — alat ini tidak menangani dekripsi.
    • Form isian interaktif atau tanda tangan digital pada PDF sumber berisiko tidak terbawa sempurna ke hasil akhir.
    • Untuk file yang sangat besar/berhalaman sangat banyak, proses berjalan di memori browser Anda — bisa terasa berat tergantung spesifikasi perangkat.
    • Butuh koneksi internet saat pertama membuka halaman (memuat pdf-lib & JSZip) — pemrosesan filenya sendiri setelah itu tidak butuh internet.
    Referensi
    • pdf-lib — pustaka JavaScript untuk membuat & memodifikasi PDF, termasuk menyalin halaman antar dokumen (lisensi MIT).
    • JSZip — pustaka JavaScript untuk membuat arsip .zip langsung di browser (lisensi MIT/GPL dual).
