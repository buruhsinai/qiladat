~/referensi-perintah-linux

Kumpulan perintah terminal Linux yang sering dipakai, terorganisir per kategori dengan tombol salin sekali ketuk. Ini referensi untuk disalin-tempel ke terminal Anda sendiri — bukan alat yang menjalankan perintah secara otomatis (dan memang tidak ada halaman web yang bisa melakukan itu, lihat penjelasan di bawah).

⚠ Kenapa ini "cuma" referensi, bukan eksekutor

Browser tidak pernah memberi halaman web akses ke shell sistem operasi — ini batas keamanan mendasar, bukan keterbatasan alat ini. Tidak ada trik JavaScript yang bisa mengubahnya. Satu-satunya cara sungguhan menjalankan perintah dari sebuah "tombol web" adalah lewat server lokal terpisah yang harus Anda install & jalankan sendiri — yang berarti Anda tetap butuh terminal untuk memulainya.

  • Semua perintah di sini harus Anda baca dulu sebelum menempelkannya — terutama yang bertanda sudo, karena berjalan dengan hak akses penuh.
  • Perintah bertanda merusak/tak bisa dibatalkan bisa menghapus data secara permanen — pastikan Anda paham betul sebelum menjalankannya.
  • Beberapa perintah mengasumsikan distribusi berbasis Debian/Ubuntu (apt) — saya tandai bila berlaku khusus.
Referensi
  • Perintah dikurasi dari dokumentasi standar man-page utilitas GNU/Linux & systemd — bukan hasil generatif tanpa dasar.
  • Untuk detail lengkap tiap perintah, jalankan man <perintah> atau <perintah> --help di terminal Anda.
